# WHAT THIS REVISION REPLACES
# The active target is r_star derived from exact ERC for each fitted model and run.
# It is not a user-entered universal percentage. This implements the new methodology.
# All three strategies share that fitted target within the same model/run.
# Targets may differ across fitted families and oracle markets; report those differences.
# No independent utility, return floor, or approximate risk-budgeting method is active.
# The former unresolved ERC choice and oracle-information optimization branch are removed.
#
# EXPERIMENT
# One chronological observed history per oracle run, no discarded prefix.
# The forecasting layer sees observed returns and public settings only.
# GARCH/GJR means and variance coefficients are fitted by conditional Gaussian MLE.
# Estimate constant innovation correlation from aligned fitted standardized residuals.
# Simulate alternative 252-day futures from the fitted endpoint using fresh forecast shocks.
# Aggregate each asset's own daily simple returns before constructing portfolios.
# Choose initial capital weights once and hold the asset quantities for the year.
# Freeze weights and forecast risk thresholds before drawing conditional oracle futures.
# Oracle futures start from the true endpoint with fresh evaluation shocks.
# All strategies and fitted families on one oracle run share its held-out terminal scenarios.
#
# MATHEMATICAL CONVENTIONS
# r_t = mu + epsilon_t; epsilon_t = sqrt(h_t) * z_t, elementwise.
# GARCH: h_next = omega + alpha * epsilon_t**2 + beta * h_t.
# GJR: h_next additionally includes gamma * epsilon_t**2 * I(epsilon_t < 0).
# With symmetric standard Gaussian innovations, p_GARCH = alpha + beta;
# p_GJR = alpha + beta + gamma/2; long-run variance = omega / (1 - p).
# Initialize the observed history at long-run variance; initialize futures at the next
# variance calculated from the final observed residual and its associated variance.
# Annual asset return: X[m,i] = product_t(1 + r[m,t,i]) - 1.
# Buy-and-hold annual portfolio return: X @ weights; annual loss: -X @ weights.
# Annual fitted mean and covariance are calculated from the same X_opt for all strategies.
# Exact ERC: weights_i * (Sigma @ weights)_i / (weights.T @ Sigma @ weights) = 1/A.
# With positive-definite covariance, positive budgets, and standard long-only unit budget,
# the normalized exact ERC solution is unique. Its mean is the maximum over that
# singleton feasible ERC set; no separate return/risk trade-off is introduced.
# r_star = mu_annual_hat @ weights_erc.
# Markowitz: minimize annual variance subject to mu_annual_hat @ weights = r_star.
# CVaR: minimize annual scenario tail loss subject to the same equality.
# Equal fitted means do not imply equal realized or oracle expected returns.
# Compounded annual portfolios are not covered by the daily Gaussian VaR/CVaR formula.
#
# PROVISIONAL SETTINGS AND LIMITATIONS
# Keep original daily four-asset M4 source and results recoverable and separately runnable.
# The five-asset pilot, equicorrelation 0.20, counts, and stress values are provisional.
# Preserve source dimensionless dynamics while scaling omega for target daily variance.
# Source-exact recovery fixtures retain source model units; they are not automatically
# investable decimal-return histories and must not be fed to annual wealth calculations.
# Apply the minus-100-percent stopping rule to investable daily decimal simple-return paths.
# Never clip, delete, resample, or silently switch return conventions after invalid paths.
# Matching daily means and long-run variances does not match full marginal distributions.
# Fixed innovation correlation does not imply identical unconditional return correlations.
# GARCH/GJR pilot persistence differs; disclose this rather than claiming isolated asymmetry.
# Stationarity and finite variance alone do not ensure every higher-order diagnostic is valid.
# Keep statistical diagnostics distinct from deterministic assertions; do not seek favorable seeds.
# No full cross-family grid, copula extension, rebalancing, or M7 replication campaign is added.
#
